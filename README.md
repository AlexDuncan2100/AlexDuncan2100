### 🚀 About Me

Cloud &amp; DevOps engineer with **6+ years of hands-on experience** (on GitHub since 2020, 60+ public repositories) building, automating and operating production-grade infrastructure.

- ☁️ Designing scalable, secure and cost-aware architectures on **AWS** and **Azure**

- 🐳 Running **microservices** on Docker, Docker Swarm and Kubernetes
